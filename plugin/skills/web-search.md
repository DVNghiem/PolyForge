# Web Search

Guidelines for using `pf_search` effectively.

## Query Construction

- **Be specific**: "axum middleware tower layer example" not "axum middleware"
- **Include year**: "tokio 2025 performance benchmark" for recent results
- **Use comparison format**: "X vs Y benchmark 2025" for technology comparisons
- **Include context**: "FastAPI dependency injection async" not just "dependency injection"

## Research Patterns

### Technology Evaluation
1. `"<tech> getting started guide"`
2. `"<tech> vs <alternative> benchmark <year>"`
3. `"<tech> production experience"`
4. `"<tech> known issues limitations"`

### Bug Investigation
1. `"<error message> <language>"`
2. `"<library> issue <symptom>"`
3. `"<library> <version> breaking changes"`

### Best Practices
1. `"<language> <topic> best practices <year>"`
2. `"<framework> <pattern> example"`

## Result Interpretation

- **Official docs** > blog posts > StackOverflow for accuracy
- **Recent results** (< 1 year) > old results for evolving technologies
- **Multiple sources** confirming the same answer = higher confidence
- **GitHub issues** linked to your problem = likely relevant
