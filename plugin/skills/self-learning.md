# Self-Learning

Self-directed knowledge acquisition strategy for PolyForge agents.

## Learning Goal Formation

Before researching, define:
1. **What do I need to know?** — Specific question or concept
2. **Why do I need it?** — What task or decision depends on this knowledge
3. **What's "good enough"?** — When can I stop and start applying

## Progressive Reading Pattern

1. **Overview**: README, official guide intro — understand what it is and why
2. **Reference**: API docs, type signatures — understand the interface
3. **Examples**: Official examples, tutorials — see it in action
4. **Source code**: Only when docs are insufficient — verify behavior
5. **Community**: GitHub issues, Stack Overflow — learn gotchas

## Note-Taking

Append findings to `workspace/learnings/<topic>.md`:
```
# <Topic>
## Summary
<3 sentences in your own words>
## Key Concepts
- <concept 1>: <brief explanation>
## Gotchas
- <surprising behavior or pitfall>
## Open Questions
- <what remains unclear>
```

## Knowledge Consolidation

After reading, write a 3-sentence summary in your own words before using the knowledge. If you can't summarize, you haven't understood it yet — read more.

## Knowing When to Stop

Stop when you can:
1. Answer your original question
2. Describe one gotcha or common pitfall
3. Write a small example from memory

Deeper reading is a trap if the question is already answered.

## Loop Pattern

```
Form question → Research → Consolidate → Validate → Apply
```

If you learn something that contradicts prior beliefs, update earlier notes.
